# 本地化约定

## 界面语言（5）

| code | 语言 | 文件 |
|---|---|---|
| `zh-CN` | 简体中文 | `www/js/i18n/zh-CN.json` |
| `zh-TW` | 繁體中文 | `www/js/i18n/zh-TW.json` |
| `en` | English（基准语言） | `www/js/i18n/en.json` |
| `ja` | 日本語 | `www/js/i18n/ja.json` |
| `ko` | 한국어 | `www/js/i18n/ko.json` |

- 语言检测：系统语言优先（`navigator.language` 映射到以上五者），找不到回退 `en`。
- 用户可在设置里强制覆盖。
- `en` 是唯一「源语言」：新文案先写进 `en.json`，其余语言在同一提交里补齐。
- 插值统一用 `{name}` 占位（如 `"{done}/{total}"`），**不翻译占位符本身**。

## 发音变体（与界面语言解耦）

| code | 名称 |
|---|---|
| `en-AU` | 澳洲英语（默认，沿用 v1 习惯） |
| `en-GB` | 英式英语 |
| `en-US` | 美式英语 |

发音变体**不随界面语言自动切换**——界面是日语的用户可能恰恰想要美式发音。默认 `en-AU`，设置里显式选择。

## 校对规则

- 日语/韩语 UI 用敬体（です・ます / 합쇼체）。
- 「听写」的译法：zh 听写 / ja 書き取り（dictation の意）/ ko 받아쓰기。
- 「单词卡」：zh 单词卡 / ja 単語カード / ko 단어 카드。
- 术语一致性优先于逐字直译；每个 key 的译文需母语者复核（阶段 2 前完成，可请学校家长帮忙）。

## 商店元数据（阶段 2）

App 名称、副标题（≤30 字符 zh / ≤30 en）、描述、关键词、截图配文都要五语言版本，单独存 `docs/store/<lang>.md`（尚未创建）。
