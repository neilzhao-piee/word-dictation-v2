# 听写小助手 ｜ 使用说明

版本 v0.2.0（2026-11-19）｜ 安卓手机 ｜ 家庭试用版

## 一、这是什么

帮家长给孩子做英文单词听写的工具。流程只有五步：

拍照单词表 → 确认单词 → 一个词一个词读（默认澳洲口音）→ 孩子在本子上写 → 拍答案核对。

核对完会显示答对几个、错在哪，并把错词记进复习本，每周还有正确率统计。适合每周一次的家庭听写，也适合任何想练英文拼写的人。

## 二、安装

1. 打开发布页（最新版）：https://github.com/neilzhao-piee/word-dictation-v2/releases/latest ，下载 word-dictation-v0.2.0-debug.apk；从家庭内测链接拿到的包直接安装即可。
2. 下载完成后点击安装。系统提示"未知来源""不允许安装"时，按提示允许浏览器安装应用。
3. 支持 Android 8.0 及以上。iOS 版本暂未提供。
4. 安装包约 54 MB，内置离线语音和离线识别模型，装好后不联网也能听写（识别会弱一些）。
5. 安装包校验值（SHA-256）见该 Release 的说明。本说明书的 PDF 也在同一个 Release 里。

## 三、开始一次听写

### 3.1 拍照单词表

首页点"开始听写"，再点"拍单词表"或"从相册选择"。

拍摄建议：一行一个单词、光线均匀、字写大一点、尽量拍满画面。识别出来的词会显示成一格一格。

### 3.2 确认单词（重要）

每个单词一格，可以：

- 直接点格子里的字修改；
- 点右侧的 × 删掉多余的词；
- 在"添加单词"框里补漏掉的词，可以一次粘贴多个（用空格分开，例如 cat dog bird）。

确认无误后点"开始听写"。程序不会跳过这一步，这是为了不给错词读错音。点之前可以顺便选一下听写顺序（见 3.3）。

### 3.3 选择听写顺序

"开始听写"按钮上方有"听写顺序"，两种：

- 随机（默认）：每次都打乱，孩子没法靠位置记住单词；
- 按顺序：按单词表从上到下读，和课本单元的顺序对得上。

选过一次会记住，下次打开还是这个选择；中途退出再进来也不会重新打乱。

### 3.4 听写

一次只读一个单词，读完后等孩子写完、家长点"确认"才读下一个。点单词本身可以重读，点"跳过"可以跳过这个词，顶部显示进度（1/10、2/10……）。

### 3.5 核对答案

全部读完点"核对答案"页面，拍孩子的答案照片。识别结果会逐词列出：

- 认错的词直接点开改；
- 多认出来的删掉，漏掉的补上；
- 点"核对答案"，显示"答对 x/y"和错词列表。

错词可以一键存进复习本，之后反复练。

## 四、设置

- 语言：简体中文、繁體中文、English、日本語、한국어。
- 英语口音：澳洲、英国、美国。
- 孩子档案：一台手机可以建多个孩子，每个孩子的历史记录、每周统计、错词本互相独立。可添加、改名、随时切换（在设置页顶部）。
- 云端识别：开启时手写识别更准（需要能用识别服务）；没配置或连不上会自动改用手机本机识别，识别率会降一些。

## 五、记录

- 历史：按 ISO 周统计正确率，看得到每周进步。
- 复习：错词本，把常错的词集中练。

## 六、隐私

拍的照片只用于识别，不保存，也不进聊天记录。开启云端识别时，照片会经加密通道送到你配置的识别服务，识别完立即丢弃；没开或连不上时，照片只在手机里处理。所有听写记录只存在这台手机上。

## 七、常见问题

- 识别不准怎么办？
  光线充足、一行一个词、字写大一点会明显变好；也可以完全手动输入。
- 没有网络还能用吗？
  能。会自动改用手机本地识别，但手写识别率会下降。
- 听写顺序能固定吗？
  能。开始前在"听写顺序"里选"按顺序"，选择会记住；想每次都是新顺序就选"随机"。
- 听不到声音？
  设置页点"测试语音"检查；同时确认手机媒体音量不为 0。
- 换手机后记录还在吗？
  记录不自动同步，换手机就是新的记录。
- 两个手机能共用一个孩子的记录吗？
  目前不支持。多个孩子在同一台手机上用"孩子档案"分开即可。

## 八、说明与限制

- 这是家庭试用版（debug 签名），正式上架 Google Play 后会提供商店版本。
- 云端识别是可选项：需要的人可以自己部署识别服务（见仓库 docs/OCR-RELAY.md）；接了服务的话，注意免费额度（Azure F0 每月约 5000 次）。
- 有问题直接反馈：截个图 + 说一下哪一步不对，比描述更有效。
