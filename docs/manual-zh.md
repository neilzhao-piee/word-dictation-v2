# 听写小助手 · 使用说明

版本 v0.1.0（2026-11-06）· 安卓手机

## 一、这是什么

帮家长给孩子做英文单词听写的工具。流程只有五步：

拍照单词表 → 确认单词 → 一个词一个词读（默认澳洲口音）→ 孩子在本子上写 → 拍答案核对。

核对完会显示答对几个、错在哪，并把错词记进复习本，每周还有正确率统计。适合每周一次的家庭听写，也适合任何想练英文拼写的人。

## 二、安装

1. 打开 GitHub 仓库的 **Releases** 页面，下载最新 `word-dictation-*.apk`。
   自己编译的话：`npm install && npx cap add android && npm run sync && npx cap run android`（需要 Android SDK）。
2. 下载完成后点击安装。系统提示"未知来源""不允许安装"时，按提示允许浏览器安装应用。
3. 支持 Android 8.0 及以上。苹果手机暂不支持（iOS 版本在计划中）。
4. 安装包约 54 MB，内置离线语音和离线识别模型，装好后不联网也能听写（识别的准确率会弱一些）。
5. 每个 Release 页面都附安装包的 SHA-256 校验值，下载后可自行核对。

## 三、开始一次听写

### 3.1 拍照单词表

首页点"开始听写"，再点"拍单词表"或"从相册选择"。

拍摄建议：一行一个单词、光线均匀、字写大一点、尽量拍满画面。识别出来的词会显示成一格一格。

### 3.2 确认单词（重要）

每个单词一格，可以：

- 直接点格子里的字修改；
- 点右侧的 × 删掉多余的词；
- 在"添加单词"框里补漏掉的词，可以一次粘贴多个（用空格分开，例如 cat dog bird）。

确认无误后点"开始听写"。程序不会跳过这一步，这是为了不给错词读错音。

### 3.3 听写

一次只读一个单词，读完后等孩子写完、家长点"确认"才读下一个。点单词本身可以重读，点"跳过"可以跳过这个词，顶部显示进度（1/10、2/10……）。

### 3.4 核对答案

全部读完点"核对答案"页面，拍孩子的答案照片。识别结果会逐词列出：

- 认错的词直接点开改；
- 多认出来的删掉，漏掉的补上；
- 点"核对答案"，显示"答对 x/y"和错词列表。

错词可以一键存进复习本，之后反复练。

## 四、设置

- 语言：简体中文、繁體中文、English、日本語、한국어。
- 英语口音：澳洲、英国、美国。
- 孩子档案：一台手机可以建多个孩子，每个孩子的历史记录、每周统计、错词本互相独立。可添加、改名、随时切换（在设置页顶部）。
- 云端识别（可选）：需要先在下面填好识别服务器地址才会启用（怎么搭见仓库 `docs/OCR-RELAY.md`）。地址留空就只用手机本机识别；上面的开关可以随时整体关掉。

## 五、记录

- 历史：按 ISO 周统计正确率，看得到每周进步。
- 复习：错词本，把常错的词集中练。

## 六、隐私

拍的照片只用于识别：不保存、不进相册、不进任何聊天记录。默认全部在这台手机上识别。

如果打开了云端识别，照片会经加密通道送到**你自己填的**识别服务器，再转给识别服务，识别完立即丢弃——服务器只在内存里过一遍，不落盘、不记录内容。没填地址就没有这一步。

所有听写记录（单词表、成绩、错词）只存在这台手机上；没有任何账号、广告或追踪。

## 七、常见问题

- 识别不准怎么办？
  光线充足、一行一个词、字写大一点会明显变好；也可以完全手动输入。
- 没有网络还能用吗？
  能。会自动改用手机本地识别，但手写识别率会下降。
- 听不到声音？
  设置页点"测试语音"检查；同时确认手机媒体音量不为 0。
- 换手机后记录还在吗？
  记录不自动同步，换手机就是新的记录。
- 两个手机能共用一个孩子的记录吗？
  目前不支持。多个孩子在同一台手机上用"孩子档案"分开即可。

## 八、说明与限制

- 代码以 MIT 协议开源，可以自己编译、自己改、自己再分发。
- 如果开了云端识别，识别服务用的是 Azure 免费额度（每月约 5000 次），够几个家庭每周听写用；额度用完会自动退回本机识别，不影响听写。
- 目前只有安卓版；iOS 在计划中。正式上架商店时会换掉占位 appId 并重做商店文案。
- 有问题直接反馈：截个图 + 说一下哪一步不对，比描述更有效。
