## Shared full description (en source, translate per locale)
Weekly English dictation for young learners. Photograph the school spelling list, confirm the
words, and the app speaks each word one at a time in Australian, British, or American English.
The child writes; you photograph the answers; the app scores and tracks mistakes by school week.
Recognition and scoring run on the phone with no network; an optional self-hosted recognition
server can be enabled for better handwriting accuracy, and it never stores or logs the photos.
No accounts, no ads, no tracking. Works fully offline.
