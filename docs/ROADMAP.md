# 路线图

## 阶段 0 · 骨架（当前）

- [x] 开发环境：Debian 13 + node 22 LTS + OpenJDK 21 + Android SDK 35
- [x] 仓库骨架：本地优先架构、i18n 五语言、批改引擎、TTS 变体层
- [ ] 产品命名 + appId 定案

## 阶段 1 · 本地优先 MVP（核心）

- [ ] 拍照 → 端上 OCR（安卓 ML Kit Text Recognition；iOS Vision/Live Text）
- [ ] 单词卡确认界面（增/删/改/排序）——产品灵魂，优先级最高
- [ ] 听写流程：逐词发音（en-AU / en-GB / en-US 可选）→ 确认下一词
- [ ] 答卷拍照 → 端上识别 → 批改 → 分数 + 错词列表
- [ ] 错词本 + 历史 + ISO 周统计（周一起始，时区可设置）
- [ ] 五语言 UI 全量落地 + 真机翻译校对
- **验收标准：飞行模式全流程可用**

## 阶段 2 · 商店包装 + Google Play 试水

- [ ] 图标 / 开屏 / 商店截图（6.7" 与 6.5"）/ 文案与关键词
- [ ] 隐私政策页（GitHub Pages 托管）+ 商店隐私标签（数据收集：无）
- [ ] 相机权限用途文案（五语言）
- [ ] Google Play 开发者账号（US$25 一次性，人工）
- 验收：自家手机可从 Play 安装并完整跑通一次听写

## 阶段 3 · iOS 上架

- [ ] 解决 Mac/Xcode（二手 Mac mini 或 Codemagic 云端 Mac，人工决策）
- [ ] iOS 原生 TTS 语音三变体实测（AVSpeechSynthesizer 自带 en-AU/en-GB/en-US）
- [ ] Apple 开发者账号（US$99/年，人工）+ 审核材料
- 验收：TestFlight 内测包 → 提审

## 阶段 4 · 云端增强（付费功能，可选）

- [ ] 云端手写识别 API（接回云主机方案：Oracle 免费层 / 悉尼 VPS + 视觉 API）
- [ ] 匿名账号 + 跨设备同步（届时才需要账号删除功能以满足 Apple 规则）
- [ ] 订阅/买断定价决策
- 前提：阶段 2/3 已有真实用户数据再投入

## 明确不做

- 社交媒体化、排行榜、广告、追踪 SDK
- 在没有用户之前自建 GPU 推理服务
